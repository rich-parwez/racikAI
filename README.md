# ✦ RacikAI — Pustaka Prompt AI Siap Pakai

**RacikAI** adalah aplikasi web ringan untuk mencari, menyesuaikan variabel, dan menyalin prompt AI (ChatGPT, Gemini, Claude) secara kilat.

![Tampilan RacikAI](link-gambar-screenshot-kamu.png)

## ✨ Fitur Utama
- 🔍 **Pencarian Cepat:** Cari prompt berdasarkan judul, deskripsi, atau kata kunci.
- 🎨 **Kustomisasi Variabel:** Isi variabel prompt secara *live* melalui modal interaktif.
- ⚡ **Salin Cepat:** Salin prompt langsung ke *clipboard* hanya dengan satu klik.
- 🌙 **Dark Mode:** Tampilan nyaman di mata dengan mode terang dan gelap.
- 📱 **Fully Responsive:** Tampilan rapi di layar HP maupun Laptop.

## 🛠️️ Teknologi yang Digunakan
- HTML5 & CSS3 (Native CSS Variables)
- Vanilla JavaScript (ES6+)
- Google Fonts (Plus Jakarta Sans & JetBrains Mono)

## 🚀 Cara Menggunakan
1. Buka website melalui tautan GitHub Pages.
2. Cari prompt yang kamu butuhkan atau filter berdasarkan kategori.
3. Klik tombol **"Sesuaikan"** untuk mengisi variabel, lalu klik **"Salin Prompt Kustom"**.
4. Tempel (*paste*) prompt tersebut langsung ke ChatGPT/Gemini/Claude kamu!
